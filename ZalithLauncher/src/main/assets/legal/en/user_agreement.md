## 2. About N3x

N3x is a free, open-source launcher for running Minecraft: Java Edition on supported Android devices. Its features may include account authentication, game and runtime downloads, version and file management, control layouts, resource discovery and downloads, log management, and multiplayer connectivity.

N3x is based on ZalithLauncher2 and is a modified version of it. It is not an official ZalithLauncher2 build.
