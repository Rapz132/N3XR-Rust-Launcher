# N3XR Rust Launcher

A modern Android Minecraft Java Edition launcher.

## About

N3XR Rust Launcher is an Android launcher project
based on Zalith Launcher 2.

The project uses PojavLauncher as its launching
core and Jetpack Compose with Material Design 3
for its user interface.

Our goal is to gradually integrate Rust native
components while maintaining compatibility
with Minecraft Java Edition.

## Features

- Modern Android interface
- Minecraft Java Edition support
- Fabric and Forge support (where compatible)
- Rust native backend (in development)
- ARM32 support (development target)

## Development Status

Currently under development.
